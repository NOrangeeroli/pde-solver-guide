LESSON 02 / 从守恒到组件

重构与界面状态

重构与 Riemann solver 各自负责什么。

本讲内容
1. 更新公式里还缺一个输入2. 重构：从格内平均，估计边界两侧状态3. Riemann 问题：这两个状态接触后，方程让它们怎样演化？4. 平流的答案：从上游取状态5. 为什么不直接平均两边？6. 把两个界面接回一个格子7. 现在可以认出四个数值模块8. 对应仓库：看接口，保留方程区别9. 自测

本讲目标：分清两个组件——重构生成界面两侧的状态，Riemann solver 利用 方程的传播规律得到界面通量。先用常速平流解释，最后对应 Burgers 代码。

1. 更新公式里还缺一个输入

上一讲已经知道怎样用通量更新平均值：

uˉin+1=uˉin+ΔtΔx(F^i−1/2−F^i+1/2). \bar u_i^{n+1}=\bar u_i^n+ \frac{\Delta t}{\Delta x}(\hat F_{i-1/2}-\hat F_{i+1/2}). uˉin+1​=uˉin​+ΔxΔt​(F^i−1/2​−F^i+1/2​).

但计算机手里只有每格平均值。即使知道物理通量 f(u)=auf(u)=auf(u)=au，仍需回答： 界面处应该把哪个状态代入 fff？

相邻两格平均值可能分别是 222 和 444。平均值既不是边界的已知值， 也没有提供边界两侧的细节。

2. 重构：从格内平均，估计边界两侧状态

最简单的办法是把每格内部都看作一个常数，值等于该格平均值。 这叫分片常数重构（piecewise constant，PC）。

text
              第 i 格        │      第 i+1 格
         重构后整格等于 2     │   重构后整格等于 4
                       uᴸ=2  │  uᴿ=4
                            i+1/2

于是，在同一个界面 i+1/2i+1/2i+1/2：

ui+1/2L=uˉi,ui+1/2R=uˉi+1. u^L_{i+1/2}=\bar u_i,\qquad u^R_{i+1/2}=\bar u_{i+1}. ui+1/2L​=uˉi​,ui+1/2R​=uˉi+1​.

上标 L/RL/RL/R 表示同一个界面的左右两侧，不是同一格的左右两个边界。 文献也常用 u−/u+u^-/u^+u−/u+ 表示这两个“迹”（trace），这里的正负不表示数值正负。

两个数可以不同：它们分别来自相邻两格对界面状态的估计。重构尚未决定 物质最终以多大速率跨过界面。

PC 只是最简单的重构选择。以后可以用邻居的信息估计格内斜率或更高阶形状， 再取边界值；MUSCL、WENO 将在这里出现。有限体积重构还需要尊重已存储的 单元平均。高阶重构背景见 Clawpack 高分辨率方法说明。

重构还包括 PPM、ENO、TENO、MP5 等常见选择。配套补充 常见重构类型提供总览：这些方法都可用于估计 界面状态，区别在于怎样利用邻居，以及怎样处理不光滑的数据。可以先看该文 的对照表，再按第三、第四讲分别拆开 MUSCL 和 WENO。

3. Riemann 问题：这两个状态接触后，方程让它们怎样演化？

在一个界面附近，暂时把初始状态看作左边恒为 uLu^LuL、右边恒为 uRu^RuR。 给定 PDE，求这两个状态接触后的局部演化，这就是 Riemann 问题。

完整 Riemann 解描述波和状态。在这里的通量形式有限体积方法中，我们利用 这个局部解得到一个公共界面通量；程序可以直接返回通量，无需输出整幅波形。 另一些方法会使用 Riemann solver 返回的波或涨落量，后续再比较接口。 定义与平流例子见 Clawpack Riemann 问题。

4. 平流的答案：从上游取状态

对 ut+aux=0u_t+a u_x=0ut​+aux​=0，先取 a=1a=1a=1：所有信息向右传播。紧接着初始时刻， 到达固定界面的状态来自左边，因此：

F^i+1/2=aui+1/2L=1×2=2. \hat F_{i+1/2}=a u^L_{i+1/2}=1\times2=2. F^i+1/2​=aui+1/2L​=1×2=2.

如果同样的左右状态遇到 a=−1a=-1a=−1，信息向左传播，界面状态来自右边：

F^i+1/2=aui+1/2R=−1×4=−4. \hat F_{i+1/2}=a u^R_{i+1/2}=-1\times4=-4. F^i+1/2​=aui+1/2R​=−1×4=−4.

负号表示向左输运，不表示浓度为负。合起来就是平流的迎风数值通量：

F^(uL,uR;a)={auL,a>0,auR,a<0,0,a=0. \hat F(u^L,u^R;a)= \begin{cases} a u^L,&a>0,\\ a u^R,&a<0,\\ 0,&a=0. \end{cases} F^(uL,uR;a)=⎩⎨⎧​auL,auR,0,​a>0,a<0,a=0.​

对这个局部 Riemann 问题，界面通量是精确的；整个网格算法仍含有重构和 时间离散近似。非线性方程及方程组的传播方向可能更复杂，不能一律照搬 “总取左值”。

5. 为什么不直接平均两边？

对 uL=2,uR=4,a=1u^L=2,u^R=4,a=1uL=2,uR=4,a=1，直接计算 a(uL+uR)/2a(u^L+u^R)/2a(uL+uR)/2 会得到 333， 而刚才的局部 Riemann 解给出 222。平均两边没有表达本例的信息传播方向。

中心平均项可以成为其他数值通量的一部分。例如后面会看到 Rusanov 在中心项 之外增加耗散项。选择一种界面公式，必须连同它的数值作用一起理解。

还要区分两个接口：

  • 物理通量 f(u)f(u)f(u)：由方程给定，输入一个状态。
  • 数值通量 F^(uL,uR)\hat F(u^L,u^R)F^(uL,uR)：由算法根据界面两侧状态等信息构造。

若两侧都是同一个状态 qqq，一致的数值通量应还原物理通量： F^(q,q)=f(q)\hat F(q,q)=f(q)F^(q,q)=f(q)。平流迎风通量满足这个条件。

6. 把两个界面接回一个格子

取三个相邻格子的平均值为 1,2,41,2,41,2,4，关注中间的第 iii 格。 令 a=1,Δx=1,Δt=0.1a=1,\Delta x=1,\Delta t=0.1a=1,Δx=1,Δt=0.1。

中间格的左界面 i−1/2i-1/2i−1/2 1,21,21,2 111
中间格的右界面 i+1/2i+1/2i+1/2 2,42,42,4 222

因此中间格更新为：

uˉin+1=2+0.11(1−2)=1.9. \bar u_i^{n+1}=2+\frac{0.1}{1}(1-2)=1.9. uˉin+1​=2+10.1​(1−2)=1.9.

右边离开的速率大于左边进入的速率，中间格的平均浓度下降。这个手算只更新 中间格，不需要端点边界条件；若要更新整个数组，还必须规定首尾如何处理。

对 a>0a>0a>0，代入 PC 和迎风通量后也可写成：

uˉin+1=uˉin−aΔtΔx(uˉin−uˉi−1n). \bar u_i^{n+1} =\bar u_i^n-\frac{a\Delta t}{\Delta x}(\bar u_i^n-\bar u_{i-1}^n). uˉin+1​=uˉin​−ΔxaΔt​(uˉin​−uˉi−1n​).

这就是一阶迎风更新。记 ν=aΔt/Δx\nu=a\Delta t/\Delta xν=aΔt/Δx，它是 (1−ν)uˉin+νuˉi−1n(1-\nu)\bar u_i^n+\nu\bar u_{i-1}^n(1−ν)uˉin​+νuˉi−1n​。本例 ν=0.1\nu=0.1ν=0.1，两系数非负、 和为 1。允许取多大的时间步会在 CFL 一讲进一步讨论。

7. 现在可以认出四个数值模块

组件 输入 输出 负责的问题
重构 单元平均及邻域 各界面的左右状态 边界两侧是什么状态？
数值通量 / Riemann 通量 左右状态、方程参数 每个界面的公共通量 以多大速率跨过界面？
守恒残差组装 相邻界面通量、网格宽度 单元平均的变化率 净输运怎样改变这一格？
时间积分 当前状态、变化率计算、时间步 下一时刻状态 怎样向前推进这一段时间？

在本讲 Euler 例子里，时间积分是“旧状态加 Δt\Delta tΔt 乘变化率”。RK 方法 会在不同阶段状态上重复重构、算通量、组装残差。边界处理和选步也属于完整 solver 的职责，后面再加入。

这四项属于五层体系中的 L1 数值职责；本讲只认清接口，还没有继续展开 L2–L4。

8. 对应仓库：看接口，保留方程区别

burgers.py 的 expert_flux 中：

python
right = shift(u, 1)
if name == "godunov":
    return godunov(u, right)

这里 u 和 right 对应 PC 得到的界面左右状态，godunov 将两个状态变成 一个公共通量。该函数实现的是 Burgers 的通量 f(u)=u2/2f(u)=u^2/2f(u)=u2/2，不是 本讲平流的 auauau；可以对应职责，不能替换成同一条数值公式。

同一文件的 weno5 分支则先生成 left_state、right_state，随后调用：

python
return godunov(left_state, right_state)

这说明重构组件改变了，后面的 Burgers Godunov 通量组件仍能复用。 此仓库实现的 WENO5 在这里输出的是界面状态；其他 WENO 形式也可能 重构分裂通量，后续讲解时会明确区分。

再往外，rhs 组装已经乘过时间步的守恒增量，step 负责 SSP-RK3 组合。 一个 Python 函数可以包含多个数值职责，因此“数值模块边界”不必等于 现有文件中的函数边界。

9. 自测

同一个界面的 uL=2,uR=4u^L=2,u^R=4uL=2,uR=4，平流速度改成 a=−1a=-1a=−1： 应该使用哪一侧状态？界面通量是多少？

展开答案

用右侧状态 444，因为信息向左传播；通量为 −1×4=−4-1\times4=-4−1×4=−4。 重构阶段依然得到 (2,4)(2,4)(2,4)，变化的是界面通量阶段的传播方向。
