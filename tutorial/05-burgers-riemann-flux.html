Burgers 与 Godunov 通量

从激波、稀疏波理解公共界面通量。

本讲目标：打开通量组件，理解为什么同样两个界面状态会产生不同的波， 以及 Godunov 怎样利用这些波确定公共界面通量。模型为一维无黏 Burgers 守恒律，所有判别公式均限定于 f(u)=u2/2f(u)=u^2/2f(u)=u2/2。

上一讲自测：五个单元平均都为 5 时，三个 WENO 候选都为 5，平滑度都为 0， 归一化权重为 (0.1,0.6,0.3)(0.1,0.6,0.3)(0.1,0.6,0.3)，最终重构状态仍为 5。

1. 从常速平流换到 Burgers

前面的平流方程为 ut+aux=0u_t+a u_x=0ut​+aux​=0，其中 aaa 是固定的传播速度。 仓库的 Burgers 方程则是：

ut+(u22)x=0,f(u)=u22. u_t+\left(\frac{u^2}{2}\right)_x=0, \qquad f(u)=\frac{u^2}{2}. ut​+(2u2​)x​=0,f(u)=2u2​.

在解光滑的地方，可以用链式法则写成：

ut+uux=0. u_t+u u_x=0. ut​+uux​=0.

局部信息传播速度为 f′(u)=uf'(u)=uf′(u)=u，所以不同状态传播的速度不同。状态为 2 的区域，其局部信息以速度 2 向右传播；状态为 -1 的区域，信息以速度 -1 向左传播。沿满足 dx/dt=udx/dt=udx/dt=u 的光滑特征线，du/dt=ut+uux=0du/dt=u_t+u u_x=0du/dt=ut​+uux​=0。

从本讲起，uuu 是可以正、可以负的 Burgers 标量状态，不再限定为非负 染料浓度。波速是 f′(u)f'(u)f′(u)，物理通量是 f(u)f(u)f(u)，两者是不同的量。 即使 u<0u<0u<0，u2/2u^2/2u2/2 仍非负，不能根据通量正负判断波往哪里走。

在跳变处不能直接使用光滑链式法则解释全部行为。确定跳变运动时，要回到 原来的积分守恒律。这也解释了为何守恒形式是 solver 的重要结构。 波速及波形的背景见 Clawpack Burgers 教程。

2. 固定一个界面，只看重构后的两个状态

令 uL,uRu^L,u^RuL,uR 是 PC、MUSCL 或 WENO 已经给出的同一界面左右状态。 将该界面移到局部坐标 x=0x=0x=0，并把本次局部问题的初始时刻记为 t=0t=0t=0：

u(x,0)={uL,x<0,uR,x>0. u(x,0)=\begin{cases} u^L,&x<0,\\ u^R,&x>0. \end{cases} u(x,0)={uL,uR,​x<0,x>0.​

此时先不关心重构用了哪一种方法。通量组件接收两个状态，负责求它们的 局部相互作用。在 Burgers 中，满足熵条件的解分成三种情况：

左右状态 局部行为
uL>uRu^L>u^RuL>uR 信息压缩，形成激波
uL<uRu^L<u^RuL<uR 信息展开，形成稀疏波
uL=uRu^L=u^RuL=uR 常值状态，没有非平凡的波

3. 激波：较快的信息追上较慢的信息

例如 uL=2,uR=1u^L=2,u^R=1uL=2,uR=1。两边信息都向右传播，但左侧更快，追上右侧。 局部解用一个传播的跳变连接两个状态，这个跳变就是激波。

它的速度不能直接取左速度 2 或右速度 1，而由守恒决定。把激波速度记作 σ\sigmaσ，避免与第三讲的重构斜率 sis_isi​ 混淆。激波两侧满足：

σ(uL−uR)=f(uL)−f(uR). \sigma(u^L-u^R)=f(u^L)-f(u^R). σ(uL−uR)=f(uL)−f(uR).

这叫 Rankine–Hugoniot 跳跃条件。直观上，在以激波速度移动的参考系中， 两边的相对通量必须匹配。代入 Burgers 的通量：

σ=(uL)2/2−(uR)2/2uL−uR=uL+uR2. \sigma=\frac{(u^L)^2/2-(u^R)^2/2}{u^L-u^R} =\frac{u^L+u^R}{2}. σ=uL−uR(uL)2/2−(uR)2/2​=2uL+uR​.

对于 (2,1)(2,1)(2,1)，σ=1.5\sigma=1.5σ=1.5。若经过一小段时间 t>0t>0t>0，激波位于 x=1.5t>0x=1.5t>0x=1.5t>0，原界面 x=0x=0x=0 已处于左状态覆盖的区域，因此 Godunov 通量是：

F^=f(2)=2. \hat F=f(2)=2. F^=f(2)=2.

若激波向左走，固定界面会处于右状态覆盖区，因此取 f(uR)f(u^R)f(uR)。 若 σ=0\sigma=0σ=0，激波停在界面，状态可以跳变，但守恒条件给出 f(uL)=f(uR)f(u^L)=f(u^R)f(uL)=f(uR)，通量仍有唯一值。

4. 稀疏波：信息向外展开

例如 uL=−1,uR=1u^L=-1,u^R=1uL=−1,uR=1。左侧信息向左，右侧信息向右，彼此分开。 局部解在中间形成从 -1 到 1 的连续过渡，而不是留下没有状态的空洞。 这就是稀疏波，也常称为稀疏波扇。

对于一般 uL<uRu^L<u^RuL<uR，在 t>0t>0t>0 时：

u(x,t)={uL,x/t<uL,x/t,uL≤x/t≤uR,uR,x/t>uR. u(x,t)=\begin{cases} u^L,&x/t<u^L,\\ x/t,&u^L\le x/t\le u^R,\\ u^R,&x/t>u^R. \end{cases} u(x,t)=⎩⎨⎧​uL,x/t,uR,​x/t<uL,uL≤x/t≤uR,x/t>uR.​

扇形区的左右边缘速度分别是 uLu^LuL、uRu^RuR。这里的线性过渡来自 局部 PDE 解的演化，不是第三讲对网格数据进行的线性重构。

Godunov 要知道固定界面 x=0x=0x=0 上的状态，相当于在 x/t=0x/t=0x/t=0 处取值：

  • 若两边状态都非负，整个扇形向右，界面取左状态。
  • 若两边状态都非正，整个扇形向左，界面取右状态。
  • 若 uL<0<uRu^L<0<u^RuL<0<uR，界面位于扇形内部，状态为 0。

因此 (−1,1)(-1,1)(−1,1) 的 Godunov 通量为 f(0)=0f(0)=0f(0)=0。仅根据激波速度公式取 某个端点，在这个稀疏波例子里会得到错误结果。

5. 为什么一定要区分压缩与展开？

只有守恒条件，还不足以排除某些不适当的间断解。Burgers 采用的熵解选择 允许压缩激波，而展开时选择稀疏波；不能把所有左右状态都当成一个激波处理。

一个直观对比是：

左、右状态 局部解 界面通量
(−1,1)(-1,1)(−1,1) 跨零稀疏波，界面状态为 0 0
(1,−1)(1,-1)(1,−1) 静止激波，两侧物理通量相同 1/21/21/2

这两个例子的端点平均都为 0，但正确通量不同。所以“先平均两个状态，再代入 物理通量”不能替代 Riemann 通量。熵条件的详细数学定义可以作为后续专题； 本讲先把它落实为上述正确的波形选择。

6. Godunov 的完整判别规则

令 fL=(uL)2/2f_L=(u^L)^2/2fL​=(uL)2/2、fR=(uR)2/2f_R=(u^R)^2/2fR​=(uR)2/2。 当 uL≤uRu^L\le u^RuL≤uR 时，可以把常值情况一起放进稀疏波分支：

F^={fL,uL≥0,fR,uR≤0,0,uL<0<uR. \hat F=\begin{cases} f_L,&u^L\ge0,\\ f_R,&u^R\le0,\\ 0,&u^L<0<u^R. \end{cases} F^=⎩⎨⎧​fL​,fR​,0,​uL≥0,uR≤0,uL<0<uR.​

当 uL>uRu^L>u^RuL>uR 时，激波速度为 σ=(uL+uR)/2\sigma=(u^L+u^R)/2σ=(uL+uR)/2：

F^={fL,σ≥0,fR,σ<0. \hat F=\begin{cases} f_L,&\sigma\ge0,\\ f_R,&\sigma<0. \end{cases} F^={fL​,fR​,​σ≥0,σ<0.​

手算例子：

uLu^LuL uRu^RuR 波形与速度 界面选择 F^\hat FF^

Godunov 在这里精确处理了给定两状态的局部问题。整个网格 solver 仍含有 空间重构与时间离散误差，因此局部“精确 Riemann 通量”不等于全局真解。

7. 对照仓库代码

burgers.py 的 godunov 的核心是：

python
fl, fr = 0.5 * left.square(), 0.5 * right.square()
rare = torch.where(left >= 0, fl, torch.where(right <= 0, fr, torch.zeros_like(fl)))
shock = torch.where(left + right >= 0, fl, fr)
return torch.where(left <= right, rare, shock)
  • 第一行计算左右物理通量。
  • 第二行计算稀疏波分支要返回的通量。
  • 第三行用 left + right 的符号判断激波方向；除以 2 不改变符号。
  • 第四行根据左右状态的大小关系选择分支。

这里 rare 与 shock 是两套候选通量，不是两条波形数组。 torch.where 把数学上的分情况选择写成张量操作；这段代码同时构造了两条 分支的候选值，并不意味着只执行被选中的 Python 分支。

8. 这个组件还能怎样拆？

数值职责 输入 输出
波型判别 左右状态的大小关系 压缩或展开
波速计算 左右状态 激波速度，或稀疏波两侧速度
界面采样 波型、波速、固定界面位置 界面状态，或静止激波的公共通量
物理通量计算 界面状态与方程 公共界面通量

这是 L1 通量模块内部的数值机制视图。实现可以合并或重排其中的计算， 例如仓库代码先算两端通量，再选择；不需要真的存下整幅 Riemann 波形。 方程提供 fff 和波速关系，重构提供左右输入，通量输出再交给守恒组装。

继续向代数层展开，Burgers Godunov 通量还有一个紧凑的等价表达：

p=max⁡(uL,0),n=min⁡(uR,0),F^=12max⁡(p2,n2). p=\max(u^L,0),\qquad n=\min(u^R,0),\qquad \hat F=\frac12\max(p^2,n^2). p=max(uL,0),n=min(uR,0),F^=21​max(p2,n2).

稀疏波跨零时两项都为零；单向稀疏波保留相应端点；左右跨零的压缩激波 则选绝对值较大的端点，对应 uL+uRu^L+u^RuL+uR 的符号。 它用正负部、平方、max 表达同一个通量，是继续拆分为基础算子的例子。 这个特定公式依赖 Burgers 通量，不能直接当作 Euler 方程组的 Godunov 公式。

9. 自测

若 uL=1,uR=−3u^L=1,u^R=-3uL=1,uR=−3：是激波还是稀疏波？波向哪边走？ 固定界面的 Godunov 通量是多少？

展开答案

因为 1>−31>-31>−3，这是激波。速度 σ=(1−3)/2=−1\sigma=(1-3)/2=-1σ=(1−3)/2=−1，向左移动。 固定界面取右状态 -3，因此通量为 (−3)2/2=4.5(-3)^2/2=4.5(−3)2/2=4.5。 波速为负但通量为正，是因为波速与通量是不同的量。
