LESSON 06 / 从守恒到组件

残差与时间推进

通量差怎样进入 Euler 与 SSP-RK3。

本讲内容
1. 通量差给出每格的变化率2. 空间离散把 PDE 变成一组随时间变化的数组方程3. Euler：用当前变化率估计一个时间步4. 为什么 Runge–Kutta 要重新计算通量？5. 仓库采用的三阶段 SSP-RK36. 对应代码：rhs 已经包含时间步7. 守恒怎样穿过多个时间阶段？8. 放回组件拆分体系9. 自测

本讲目标：把“重构 → 通量 → 守恒组装”接成一个计算变化率的过程，再理解 时间积分器怎样反复调用它。学完后，应能区分状态、通量、变化率和更新增量。 继续使用一维、均匀网格、无源项的有限体积方法；手算采用常速平流，代码 接口对应仓库的 rhs 与 step。

上一讲自测：Burgers 左右状态为 1、-3 时，激波向左传播，界面通量为 4.5。 现在我们已经能计算每个界面的通量，接下来要更新所有格子的平均值。

1. 通量差给出每格的变化率

对第 iii 格，左界面流入、右界面流出。定义：

Li(U)=−F^i+1/2(U)−F^i−1/2(U)Δx=左通量−右通量Δx. \mathcal L_i(U)= -\frac{\hat F_{i+1/2}(U)-\hat F_{i-1/2}(U)}{\Delta x} =\frac{\text{左通量}-\text{右通量}}{\Delta x}. Li​(U)=−ΔxF^i+1/2​(U)−F^i−1/2​(U)​=Δx左通量−右通量​.

这里 U=(uˉ0,uˉ1,…)U=(\bar u_0,\bar u_1,\ldots)U=(uˉ0​,uˉ1​,…) 表示整个单元平均数组。 通量依赖状态，因此 L\mathcal LL 是“输入一个状态数组，输出一个变化率数组”的函数。 符号 L\mathcal LL 只是名称，不表示这个函数一定线性；Burgers 通常是非线性的。

举例：某格平均值为 4，左右通量分别为 3、1，Δx=0.5\Delta x=0.5Δx=0.5。

Li=3−10.5=4. \mathcal L_i=\frac{3-1}{0.5}=4. Li​=0.53−1​=4.

这表示当前每单位时间平均值增加约 4，还不是“这一时间步增加 4”。 若 Δt=0.1\Delta t=0.1Δt=0.1，按当前变化率估算的增量才是 0.1×4=0.40.1\times4=0.40.1×4=0.4。

文献和代码会把这类量叫作空间算子、半离散右端、空间残差或 RHS。 “残差”也可能采用相反符号，或者表示别的方程中的误差；必须看定义。 本讲统一用 L\mathcal LL 表示尚未乘时间步的变化率。

2. 空间离散把 PDE 变成一组随时间变化的数组方程

空间已经划成格子，时间暂时保留为连续变量，我们就得到：

dUdt=L(U). \frac{dU}{dt}=\mathcal L(U). dtdU​=L(U).

这叫半离散形式，也属于 method of lines（线方法）的思路。“半”是因为空间 已经离散，时间还没离散。此时每个数组元素都是一个随时间变化的未知量。

一次 L(U)\mathcal L(U)L(U) 计算包含：

text
当前阶段的单元平均 U
    ↓  取得这个阶段的邻域与边界数据
重构：得到各界面的左右状态
    ↓
数值通量：得到各界面的公共通量
    ↓
守恒组装：左通量减右通量，再除以格宽
    ↓
当前阶段的变化率 L(U)

时间积分器负责选择在哪些阶段状态上调用这个过程，以及怎样组合这些结果。 例如 SharpClaw 也把 WENO 重构与 Runge–Kutta 时间积分配合使用，见 Clawpack 的求解器说明。 它的波传播空间实现与本讲的通量差实现有区别，这里对应的是时空分工。

3. Euler：用当前变化率估计一个时间步

最简单的显式时间推进是前向 Euler：

Un+1=Un+Δt L(Un). U^{n+1}=U^n+\Delta t\,\mathcal L(U^n). Un+1=Un+ΔtL(Un).

它假设在这一个短时间步内，可以用起点的变化率近似整段时间的变化。 上面的单格例子就得到 4+0.1×4=4.44+0.1\times4=4.44+0.1×4=4.4。

现在改用一个能把所有格子一起算完的例子。取三个周期网格，Δx=1\Delta x=1Δx=1， 初始平均值为 Un=(1,2,4)U^n=(1,2,4)Un=(1,2,4)。求解常速平流 ut+ux=0u_t+u_x=0ut​+ux​=0，使用 PC 重构与迎风通量。速度为正，每格右界面通量就是该格状态：

F^=(1,2,4),L(Un)=(4−1,  1−2,  2−4)=(3,−1,−2). \hat F=(1,2,4),\qquad \mathcal L(U^n)=(4-1,\;1-2,\;2-4)=(3,-1,-2). F^=(1,2,4),L(Un)=(4−1,1−2,2−4)=(3,−1,−2).

第一格的左通量为 4，因为周期边界把最后一格与第一格连接。 取 Δt=0.1\Delta t=0.1Δt=0.1，Euler 给出：

UEulern+1=(1,2,4)+0.1(3,−1,−2)=(1.3,1.9,3.8). U^{n+1}_{\mathrm{Euler}}=(1,2,4)+0.1(3,-1,-2)=(1.3,1.9,3.8). UEulern+1​=(1,2,4)+0.1(3,−1,−2)=(1.3,1.9,3.8).

这个例子使用平流通量 f(u)=uf(u)=uf(u)=u，不是第五讲的 Burgers 通量 u2/2u^2/2u2/2。 两者的通量公式不同，但都可接到相同的通量差组装和时间推进接口。

4. 为什么 Runge–Kutta 要重新计算通量？

在 Euler 得到的新状态 (1.3,1.9,3.8)(1.3,1.9,3.8)(1.3,1.9,3.8) 上重新计算，会得到：

L(1.3,1.9,3.8)=(2.5,−0.6,−1.9). \mathcal L(1.3,1.9,3.8)=(2.5,-0.6,-1.9). L(1.3,1.9,3.8)=(2.5,−0.6,−1.9).

它已经不同于起点的 (3,−1,−2)(3,-1,-2)(3,−1,−2)。流动在改变状态，状态又在改变通量和 变化率。即使重构方法、通量方法、参数都保持不变，中间结果通常仍会改变。

Runge–Kutta 方法会构造若干内部阶段状态，在这些状态上重新评估变化率， 再按特定系数组合，以提高时间近似精度。它不是把同一份起点通量重复加几次。 这些阶段通常也不是必须保存的真实时间快照；它们首先是积分公式的中间量。

5. 仓库采用的三阶段 SSP-RK3

对本讲不显含时间的 L(U)\mathcal L(U)L(U)，仓库公式为：

U(1)=Un+Δt L(Un),U(2)=34Un+14[U(1)+Δt L(U(1))],Un+1=13Un+23[U(2)+Δt L(U(2))]. \begin{aligned} U^{(1)} &= U^n+\Delta t\,\mathcal L(U^n),\\ U^{(2)} &= \frac34 U^n+ \frac14\left[U^{(1)}+\Delta t\,\mathcal L(U^{(1)})\right],\\ U^{n+1} &= \frac13 U^n+ \frac23\left[U^{(2)}+\Delta t\,\mathcal L(U^{(2)})\right]. \end{aligned} U(1)U(2)Un+1​=Un+ΔtL(Un),=43​Un+41​[U(1)+ΔtL(U(1))],=31​Un+32​[U(2)+ΔtL(U(2))].​

先看结构：第一阶段做一次 Euler 预测；第二、第三阶段分别从新的阶段状态 计算 Euler 候选，再与保留的原始状态 UnU^nUn 加权组合。每次都要用该阶段 状态重新做重构、通量和残差计算。这一步总共评估三次 L\mathcal LL。

三阶段公式与时间参数的写法也可对照 Gkeyll 的 SSP-RK 说明。 其空间离散使用 DG，但这里的时间组合公式相同。对于显含时间的方程或边界， 三个变化率分别在 tnt^ntn、tn+Δtt^n+\Delta ttn+Δt、tn+Δt/2t^n+\Delta t/2tn+Δt/2 评估， 不能把阶段编号直接当成按顺序增加的物理时刻。

继续用上面的三格平流例子：

当前用于计算的状态 重新算出的变化率 经过本阶段公式后的状态
Un=(1,2,4)U^n=(1,2,4)Un=(1,2,4) (3,−1,−2)(3,-1,-2)(3,−1,−2) U(1)=(1.3,1.9,3.8)U^{(1)}=(1.3,1.9,3.8)U(1)=(1.3,1.9,3.8)
U(1)=(1.3,1.9,3.8)U^{(1)}=(1.3,1.9,3.8)U(1)=(1.3,1.9,3.8) (2.5,−0.6,−1.9)(2.5,-0.6,-1.9)(2.5,−0.6,−1.9) U(2)=(1.1375,1.96,3.9025)U^{(2)}=(1.1375,1.96,3.9025)U(2)=(1.1375,1.96,3.9025)
U(2)=(1.1375,1.96,3.9025)U^{(2)}=(1.1375,1.96,3.9025)U(2)=(1.1375,1.96,3.9025) (2.765,−0.8225,−1.9425)(2.765,-0.8225,-1.9425)(2.765,−0.8225,−1.9425) Un+1=(1.276,1.9185,3.8055)U^{n+1}=(1.276,1.9185,3.8055)Un+1=(1.276,1.9185,3.8055)

例如第二阶段第一格为 34×1+14(1.3+0.1×2.5)=1.1375\tfrac34\times1+\tfrac14(1.3+0.1\times2.5)=1.137543​×1+41​(1.3+0.1×2.5)=1.1375。 最终只从 tnt^ntn 推进到 tn+0.1t^n+0.1tn+0.1，不是推进到 tn+0.3t^n+0.3tn+0.3； 中间的混合系数是方法的一部分，不能省略成三次连续 Euler。

三阶段指三次变化率评估，三阶指时间设计精度。这两个概念不同，其他 RK 方法的阶段数不一定等于精度阶数。WENO5 配 SSP-RK3 则分别涉及空间五阶设计 和时间三阶设计；整个求解的误差还依赖光滑性、限制机制和步长选择。

6. 对应代码：rhs 已经包含时间步

burgers.py 中的 rhs 核心是：

python
flux = expert_flux(u, solver) if isinstance(solver, str) else solver(u, dt_dx)
return -dt_dx * (flux - shift(flux, -1))

flux[i] 是右界面通量，shift(flux, -1)[i] 是左界面通量， dt_dx 是 Δt/Δx\Delta t/\Delta xΔt/Δx。因此它返回的是：

rhs⁡(U,Δt/Δx,…)=Δt L(U), \operatorname{rhs}(U,\Delta t/\Delta x,\ldots) =\Delta t\,\mathcal L(U), rhs(U,Δt/Δx,…)=ΔtL(U),

不是本讲定义的 L(U)\mathcal L(U)L(U)。看懂这个区别，才能正确对应 step：

python
u1 = u + rhs(u, dt_dx, solver)
u2 = 0.75 * u + 0.25 * (u1 + rhs(u1, dt_dx, solver))
return u / 3 + (2 / 3) * (u2 + rhs(u2, dt_dx, solver))

这里不用再乘一次 dt；那会把增量额外缩放一次。另一种常见接口是让 rhs 只返回变化率，再由积分器乘 dt。两种都能实现相同公式，但组件替换时必须 统一约定，不能只根据 rhs 这个函数名判断。

数值职责 本仓库早期接口 输出的含义
重构与界面通量 expert_flux(u, name) 每个右界面的公共通量
通量差组装并乘时间步 rhs(u, dt_dx, solver) 当前阶段的 Euler 增量
时间阶段组合 step(u, dt_dx, solver) 一个完整时间步后的状态

对固定的经典通量，本讲可写成 L(U)\mathcal L(U)L(U)。仓库还允许通量 callable 接收 dt_dx，学习路由可能据此改变通量；这时空间映射本身也可能依赖步长。 rhs 返回带时间步增量的约定仍然不变，但不能不加检查地套用固定半离散 算子的精度结论。

7. 守恒怎样穿过多个时间阶段？

周期均匀网格的通量差相加会消去内部交换：

Δx∑iLi(U)=−∑i(F^i+1/2−F^i−1/2)=0. \Delta x\sum_i\mathcal L_i(U) =-\sum_i(\hat F_{i+1/2}-\hat F_{i-1/2})=0. Δxi∑​Li​(U)=−i∑​(F^i+1/2​−F^i−1/2​)=0.

因此一次 Euler 候选保持总量 Δx∑iuˉi\Delta x\sum_i\bar u_iΔx∑i​uˉi​。SSP-RK3 又把总量 相同的两个状态按和为 1 的系数组合，仍保持该总量。上表每个阶段的三个值 都加起来等于 7；在浮点实现中允许舍入误差。

这个性质依靠相邻格使用同一个公共界面通量。非周期问题的总量还要计入 边界流入流出；有源项时也要计入源项贡献。

SSP 意为 strong stability preserving（强稳定性保持）。其思想是在满足 相应步长限制时，继承前向 Euler 已有的某种凸稳定性性质。名称本身并不保证 任意空间模块或任意学习通量都稳定；上面的守恒证明也不等于稳定性证明。 关于这一条件性保证，见 Gottlieb、Shu 与 Tadmor 的 SSP 综述。

8. 放回组件拆分体系

到这里，一步算法的外层与内层关系已经清楚：

text
完整时间步 step
    ├─ 在 Uⁿ 上调用空间计算，形成第一阶段
    ├─ 在 U⁽¹⁾ 上再次调用空间计算，形成第二阶段
    └─ 在 U⁽²⁾ 上再次调用空间计算，得到 Uⁿ⁺¹

每次空间计算内部：重构 → 通量 → 通量差组装

L0 可以描述这个完整时间步；L1 可以区分重构、通量、残差组装及时间阶段的 职责；各职责再向更细机制展开。三次空间调用是计算次数，L0–L4 是展开粒度， 两者没有一一对应关系。

同一个空间方法可以配合不同的时间积分器，前提是接口和数值条件兼容。 更换 WENO 的权重与更换 RK 的阶段系数发生在不同位置；后者的系数还必须满足 对应的精度和稳定性条件，不能随意混合后仍称为原来的 RK 方法。

9. 自测

某格当前平均值为 2，左通量为 5，右通量为 3，Δx=0.5\Delta x=0.5Δx=0.5， Δt=0.1\Delta t=0.1Δt=0.1。

  1. 空间变化率 Li\mathcal L_iLi​ 是多少？
  2. 本仓库 rhs 在该格返回多少？Euler 更新后是多少？
  3. 使用 SSP-RK3 时，后两个阶段能直接复用起点算出的左右通量吗？
展开答案

变化率为 (5−3)/0.5=4(5-3)/0.5=4(5−3)/0.5=4；rhs 返回 0.1×4=0.40.1\times4=0.40.1×4=0.4；Euler 得到 2.42.42.4。一般不能复用原来的通量：阶段状态变化后，需要重算对应的 重构与通量。这道题只给出一格起点通量，信息不足以算出完整 RK3 的最终值。
