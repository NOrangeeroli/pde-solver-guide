本讲目标：解释计算区域两端的邻居从哪里来、时间步长由什么决定，并说明
这两个组件怎样参与每次空间计算和完整时间步。继续采用一维均匀网格、
无源项、显式有限体积方法；不把这里的步长公式直接推广到所有离散方法。

上一讲自测：左通量 5、右通量 3、格宽 0.5 时，变化率是 4；时间步 0.1
对应增量 0.4，平均值从 2 变成 2.4。`rhs` 已包含时间步，不能再乘一次。

## 1. 边缘格也需要邻居

MUSCL 会读取左右邻格，WENO 会读取更宽的模板。在内部格子上，这些值都在
数组里；到了最左或最右边，模板的一部分就伸出了计算区域。

例如只有四个物理单元，平均值为 \((1,2,4,8)\)：

```text
缺失的左邻居 │ 1   2   4   8 │ 缺失的右邻居
```

缺失值不是单纯的数组问题。它们取决于我们求解的物理问题：两端是否连接、
外部是否有输入、右侧是否允许流出、边界是否是一堵墙。

初始条件给出“开始时区域内是什么状态”；边界条件给出“演化时区域与外部
怎样相接”。二者都属于问题定义。

## 2. Ghost cells：为模板提供域外数据

常见实现是在两侧增加辅助单元，称为 ghost cells（幽灵单元、虚拟单元）。
如果每侧增加两格：

```text
左侧 ghost   │ 物理单元      │ 右侧 ghost
 g₋₂   g₋₁  │ 1   2   4   8 │ g₄   g₅
```

先根据边界规则填写它们，重构就可以继续读取完整模板。它们用于辅助计算，
不作为额外物理体积加入总质量，也不作为独立的物理未知量一直推进。

同一组物理单元，在不同边界下会得到不同延拓：

| 边界规则 | 加两层 ghost 后的示意数组 |
|---|---|
| 周期：首尾相接 | `4 8 │ 1 2 4 8 │ 1 2` |
| 两端常数外推 | `1 1 │ 1 2 4 8 │ 8 8` |
| 左侧给定常数外部状态 0，右侧外推 | `0 0 │ 1 2 4 8 │ 8 8` |

这几行是不同边界问题，不能为了计算方便随意互换。ghost cells 也不是唯一
实现方式：周期索引、单边重构、直接构造边界数值通量，都可以提供相应闭合。
常见的 ghost 填充方式可对照
[Clawpack 边界条件文档](https://www.clawpack.org/bc.html)。

本表的两层只用于演示排布。实际层数取决于整个界面计算所需的最远邻居，
不能把“WENO5”直接读成“需要五层 ghost”。例如第四讲的左右状态合起来使用
偏移 -2 到 +3；若在两端也直接计算完整的双侧 WENO5 模板，常用每侧三层。
专门的边界重构可以采用不同安排。

## 3. 常见边界各表达什么？

| 类型 | 物理含义与常见实现 | 需要分清的地方 |
|---|---|---|
| 周期 periodic | 从另一端复制数据，区域像一个环 | 第一格与最后一格互为邻居 |
| 入流 inflow / 给定外部状态 | 用外部数据决定进入区域的信息 | 不能把域内所有分量都不加区分地强制固定 |
| 出流 outflow / 常数外推 | 把最近内部格的状态复制到外侧 | 是一种简单数值闭合，不保证对所有波都完全无反射 |
| 反射壁面 reflecting wall | 按镜像关系构造外侧状态 | 不同物理分量可能需要不同符号 |

以 \(u_t+a u_x=0\) 为例，若 \(a>0\)，信息向右传播：左端需要提供入流数据，
右端的信息来自区域内部。若 \(a<0\)，两端角色反过来。对有多种波速的方程组，
同一个边界可能同时存在进入和离开的波，需要按入射特征处理，不能只看流体
速度的正负。

反射壁面的例子是静止的一维 Euler 固壁：镜像 ghost 状态通常保持密度与
总能量不变、反转法向动量，即
\((\rho,m,E)\mapsto(\rho,-m,E)\)。配合相容的通量处理得到不可穿透边界。
这不是让全部守恒量变号，也不是让墙上的每个通量分量都为零；壁面仍可传递
压力产生的动量通量。仓库对应的符号约定见后文 `wall_parity`。

高阶方法还需区分“边界面上的给定值”和“域外单元平均值”。把一个时变的
边界点值原样复制到所有 ghost，不一定保持高阶精度。实际填充要与方程和
重构一致；[Clawpack 的时变平流入流例子](https://www.clawpack.org/gallery/_static/apps/fvmbook/chap7/advinflow/README.html)
展示了利用传播关系构造域外数据的做法。

## 4. 边界在每个 RK 阶段都要参与空间计算

第六讲的 SSP-RK3 分别计算
\(\mathcal L(U^n)\)、\(\mathcal L(U^{(1)})\)、\(\mathcal L(U^{(2)})\)。
每次都必须使用**当前阶段**对应的边界数据：

```text
阶段状态 → 边界延拓/邻居读取 → 重构 → 通量 → 物理单元的变化率
```

例如周期边界从另一端取值，而另一端的阶段状态已经改变；反射、外推也需要
当前内部状态。时变边界还要使用正确的阶段时间：本教程三阶段 SSP-RK3 的
变化率评估时间依次为 \(t^n\)、\(t^n+\Delta t\)、\(t^n+\Delta t/2\)。

对于固定外部常数，填入的数值可能相同，但这不意味着可以统一复用整份旧的
扩展数组。边界闭合是空间计算的输入步骤，不是在所有 RK 阶段结束后再修补。

非周期情况下，\(N\) 个物理单元有 \(N+1\) 个不同的边界/内部界面。
通量组装必须包含最左、最右两个外边界通量。以从 0 开始的界面数组 `F` 为例：

```python
# F[0] 是左外边界，F[N] 是右外边界；这里输出变化率，未乘 dt。
rate = -(F[1:] - F[:-1]) / dx
```

全域总量变化为左外边界通量减右外边界通量。不能在这个数组上继续用周期
roll 连接两端，否则就改变了边界问题。

## 5. CFL 数：一步传播距离与格宽之比

对常速平流，一段时间 \(\Delta t\) 内信息移动距离 \(|a|\Delta t\)。与格宽
比较，定义无量纲的 Courant 数，通常也称 CFL 数：

\[
\nu=\frac{|a|\Delta t}{\Delta x}.
\]

例如 \(|a|=2\)、\(\Delta x=0.1\)、\(\Delta t=0.02\)，则 \(\nu=0.4\)：
一步内信息传播距离相当于 0.4 个格宽。

对局部显式方法，算法能从哪些邻居取得信息是有限的。时间步过大时，真实
传播所依赖的数据可能超出算法能覆盖的范围。CFL 条件从这个依赖关系限制
时间步；它不是一个对所有算法都相同的“只能走一格”规则。
依赖域的解释及必要条件可见
[Toby Driscoll 的 CFL 讲义](https://tobydriscoll.net/fd-spectral-notes/advection/cfl.html)。

## 6. 用 PC + 迎风 + Euler 看懂为什么会有限制

取 \(a>0\)，PC 迎风通量为 \(\hat F_{i+1/2}=a\bar u_i\)。代入 Euler：

\[
\begin{aligned}
\bar u_i^{n+1}
&=\bar u_i^n-\frac{a\Delta t}{\Delta x}(\bar u_i^n-\bar u_{i-1}^n)\\
&=(1-\nu)\bar u_i^n+\nu\bar u_{i-1}^n.
\end{aligned}
\]

当 \(0\le\nu\le1\) 时，两项系数非负、和为 1，结果位于这两个输入值之间。
取本格为 1、上游格为 0：

| Courant 数 | 更新结果 | 含义 |
|---|---|---|
| \(\nu=0.4\) | \(0.6\times1+0.4\times0=0.6\) | 保持在输入范围内 |
| \(\nu=1\) | \(0\times1+1\times0=0\) | 从上游平移一格 |
| \(\nu=1.2\) | \(-0.2\times1+1.2\times0=-0.2\) | 从非负输入产生负值 |

因此这套具体组合采用 \(\nu\le1\)。更换重构、通量、积分器或维数后，
允许值必须重新确定；满足一个形式上的 CFL 比例也不自动证明稳定。
特别是 WENO 模板更宽，不能据此直接把允许时间步按模板格数放大。

### 补充：CFL 通常只取决于重构组件吗？

不只取决于重构。日常说“CFL 取多少”时，至少要区分三个量：

| 量 | 含义 |
|---|---|
| 实际 Courant 数 \(\nu=a_{\max}\Delta t/\Delta x\) | 在给定速度定义下，本次时间步与空间尺度的比例 |
| 允许上限 \(C_{\max}\) | 某套完整离散在指定稳定性要求下可接受的界限 |
| 目标系数 \(C_{\mathrm{target}}\) | 实际选步使用的设置，通常留出余量，并考虑精度要求 |

重构属于空间离散的一部分。允许上限来自空间离散与时间积分的配合，还受
方程、网格、维数和边界处理影响。同一离散的线性稳定、TVD、保正性要求，
也可能对应不同的步长限制，不能把它们统称为同一个已证明的“稳定”。

| 因素 | 怎样影响选步或允许上限 |
|---|---|
| 方程与当前状态 | 决定传播速度，例如 Burgers 的 \(|u|\)、Euler 的 \(|v|+c\) |
| 重构与 limiter | 改变从单元状态到界面状态的空间算子及其非线性限制 |
| 数值通量与波速估计 | 改变波传播和数值耗散；固定重构也可能得到不同限制 |
| 时间积分器 | Euler、不同 RK 方法具有不同的稳定性质，需要与空间算子匹配 |
| 网格、维数与边界 | 改变空间尺度、各方向耦合与边界闭合；一维公式不能原样套用 |

若模型还有显式处理的扩散或刚性源项，它们也可能另外限制时间步。

一个具体反例：固定一维周期常速平流、均匀网格、**PC 重构与前向 Euler**，
只改变数值通量。取 \(a>0\)、\(\nu=a\Delta t/\Delta x\)：

| 通量选择 | 更新公式 | 稳定性结论 |
|---|---|---|
| 迎风，\(\hat F=a u^L\) | \(\bar u_i^{n+1}=(1-\nu)\bar u_i^n+\nu\bar u_{i-1}^n\) | \(0\le\nu\le1\) 时为单调的非负加权更新 |
| 中心，\(\hat F=a(u^L+u^R)/2\) | \(\bar u_i^{n+1}=\bar u_i^n-\tfrac\nu2(\bar u_{i+1}^n-\bar u_{i-1}^n)\) | 固定任意非零 Courant 数细化网格时，线性稳定性不成立 |

第二行就是前向时间、中心空间的 FTCS 平流离散。它没有一个与第一行类似
的正常正 CFL 稳定区间，不能用“也采用 PC”推断其允许步长。
中心通量配显式 Euler 的问题可对照
[TU Delft 的有限体积平流教材](https://mude.citg.tudelft.nl/book/2024/fvm/advection_1.html)。

时间积分同样参与限制。例如 SSP 方法的一类条件性保证写作
\(\Delta t\le C_{\mathrm{SSP}}\Delta t_{\mathrm{FE}}\)：
\(\Delta t_{\mathrm{FE}}\) 是当前空间离散配前向 Euler 时满足所需凸稳定性
性质的步长界限，\(C_{\mathrm{SSP}}\) 由积分器决定。本教程的三阶段 SSP-RK3
具有 \(C_{\mathrm{SSP}}=1\)；三阶段并不意味着这一保证允许三倍步长。
这是保证条件，不应等同于所有问题上的最大线性稳定步长。见
[Gottlieb、Shu 与 Tadmor 的 SSP 综述](https://math.umd.edu/~tadmor/pub/linear-stability/Gottlieb-Shu-Tadmor.SIREV-01.pdf)。

实际项目有时按重构名称配置默认 CFL，是因为方程、通量、积分器和网格设置
已经固定。这种配置表记录的是特定组合的设置，不能直接当作该重构在任意
组合下的固有常数。在我们的组件体系里，重构、通量或积分器一旦被替换，
都应重新核对该组合适用的步长约束。

## 7. 非线性方程怎样估计速度并选步？

一维均匀网格中，常用一个与当前离散相匹配的最大速度估计 \(a_{\max}\)：

| 方程 | 典型的物理波速信息 |
|---|---|
| 常速平流 | \(|a|\) |
| Burgers，\(f(u)=u^2/2\) | \(|f'(u)|=|u|\)，速度随状态变化 |
| 一维理想气体 Euler | 速度 \(v-c,v,v+c\)，最大绝对值为 \(|v|+c\)，\(c\) 是声速 |

选取对该空间方法与积分器合适的目标系数 \(C_{\mathrm{target}}\)，可以写成：

\[
\Delta t=\min\left(
C_{\mathrm{target}}\frac{\Delta x}{a_{\max}},\quad t_{\mathrm{end}}-t
\right),\qquad a_{\max}>0.
\]

例如 Burgers 状态为 \((-1,0.5,2)\)，先用最大绝对状态估计速度 2，
取 \(\Delta x=0.1\)、\(C_{\mathrm{target}}=0.4\)，得到 \(\Delta t=0.02\)。
若距终点只剩 0.007，就用 0.007，避免越过目标时刻。

速度估计必须考虑实际需要的状态范围。重构界面值可能与单元平均不同，外部
入流也可能带来更快的波；数值通量采用的耗散速度同样影响稳定限制。
仅仅对内部单元平均取一次最大值，不是对所有组合都充分的保证。

若相关传播速度全部为零，不能直接除以零；可以使用有限的步长上限，在本讲
无其他约束的情形下由剩余时间等给出。这个分支不能忽略非零的边界输入。

常见显式 RK 流程在每个**完整时间步**开始时选取 \(\Delta t\)，本步各阶段
使用同一个 \(\Delta t\)，下一完整步再根据新状态更新。若需监测阶段速度
并缩步，应按设计拒绝并重做整步；不能擅自为 RK 的三个阶段换成三个不同
步长，同时仍使用原来的组合系数。

实际的“验收失败 → 缩步 → 重做”由时间步控制器组织。它包在完整单步计算
外层，和步内的重构、通量、RK 阶段职责不同，详见配套补充
[重试属于哪个组件？](07a-step-controller-retries.md)。

## 8. 对应早期代码与较新的组件

当前目录 [`burgers.py`](../../solver_sculpt/burgers.py) 的 `shift` 是：

```python
return torch.roll(u, -k, -1)
```

它读取 \(u_{i+k}\)，越界后绕回另一端，因此已经包含周期边界语义。
这里没有显式分配 ghost 数组，但并不缺少边界处理。把 `roll` 换成零填充
或复制端点会改变边界问题，不能视为普通的索引实现替换。

同一文件的 `training_data` 在初始状态上计算：

```python
dt_dx = 0.35 / fine.abs().amax(-1, keepdim=True).clamp_min(0.1)
```

它按每条样本的初始最大绝对状态选择 \(\Delta t/\Delta x\)，并用 0.1 作
分母下限；0.35 是这个数据生成配置的系数。随后循环固定复用该比值，
没有每个时间步重新选取。不要把这里描述成逐步自适应选步，也不要把 0.35
当作所有算法的理论上限。`step` 本身接收已有的 `dt_dx`，不负责选择它。

## 9. 放回一整步的流程

```text
当前物理状态、方程、边界信息
    ↓
估计速度 → 根据 CFL 和时间上限选 dt
    ↓
RK 第一阶段：边界 → 重构 → 通量 → 残差 → 阶段组合
    ↓
RK 第二阶段：用新阶段状态重复上述空间计算与组合
    ↓
RK 第三阶段：用新阶段状态重复上述空间计算与组合
    ↓
得到下一状态，时间增加 dt
```

从拆分粒度看，边界模块内部可以继续区分索引映射、外部值注入、分量符号
或入射投影；CFL 模块内部可以区分方程波速、最大值归约、除法、上限截断与
零速度分支。它们会展开到 L2–L4，但具体节点归属以实现注册为准。

到这里，求解器除了重构、通量、残差和时间组合，还需要边界与选步职责。
这些组件参与的位置不同；不能把它们全部理解成沿数组依次执行一次的层。
