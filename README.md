# PDE Solver Guide

统一公共文档：入门教程、HyperBench、组件 DSL。

网站：https://norangeeroli.github.io/pde-solver-guide/

静态目录可直接托管，无 CDN、分析追踪或后端。数学公式预渲染为 HTML/MathML；Mermaid 和字体资源随站点发布。
